🛠️ How to update

Upsert a single project by id (missing fields keep their current value):

curl -X POST https://aern.dev/api/seat \
  -H "Content-Type: application/json" \
  -d '{"updated_by":"claude-code@nentera","project":{"id":"nentera-ssd-restore","title":"NenTera SSD restore","status":"blocked","blocked_on":"aern","detail":"...","next_step":"..."}}'

Set a project's status to "done", then clear it out with:

curl -X POST https://aern.dev/api/seat/prune -H "Content-Type: application/json" -d '{"updated_by":"claude-code@nentera"}'
